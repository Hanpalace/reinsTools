# 再保运维工具 功能与实现说明

> 版本：0.1.0 · 最后更新：2026-09-12 · 配套使用手册见 [使用文档.md](使用文档.md)

## 项目概述

再保运维工具 是一个基于 **Tauri 2（Rust 后端）+ Vue 3 / Vite 6 / TypeScript + Naive UI** 的跨平台桌面应用，面向再保险结算运营场景，核心能力是**MySQL 数据批量导入**及其配套的连接管理、日志审计体系。

技术栈：Tauri 2 · Vue 3（Composition API）· Naive UI · UnoCSS · Pinia · vue-router · vue-i18n · sqlx（MySQL/PostgreSQL/SQLite）· SQLite（台账）· pnpm

## 二、数据连接配置（/data/connection）

### 功能

- **查询**：按数据库类型（全部/MySQL/PostgreSQL/SQLite）、连接名称模糊、数据库名模糊过滤；分页（10/20/50）
- **新增/编辑**：弹窗表单（连接名称、数据库类型、主机地址、端口、用户名、密码、数据库名）；切换类型自动填默认端口（3306/5432），SQLite 禁用端口、主机栏提示文件路径
- **测试联通性**：表单内与列表行内均可触发，真实连接 + `SELECT 1` 验证
- **删除**：带确认弹窗
- 列表展示：类型彩色标签（MySQL 绿 / PG 蓝 / SQLite 黄）、主机等宽字体超长省略

### 实现细节

- **持久化**：[db.rs](../src-tauri/src/db.rs)，文件 `{app_config_dir}/connections.json`。每条配置带稳定 `id`（Unix 纳秒 hex），增删改按 id 定位——编辑改名不会产生重复条目；旧数据无 id 时加载自动补齐（一次性迁移）
- **写入安全**：tokio Mutex 串行化读-改-写（防并发丢失更新与 tmp 冲突）；temp 文件 + rename 近似原子写；文件 I/O 全走 `tokio::fs` 不阻塞异步线程
- **密码**：明文存本地 JSON（代码注释声明的已知取舍，本地单用户工具）
- **连接测试**：sqlx 按类型直连（`MySqlConnectOptions`/`PgConnectOptions`/`SqliteConnectOptions` builder，避免密码特殊字符 URL 编码问题），成功后执行 `SELECT 1` 验证真实往返；整体 5 秒超时防挂起；SQLite `create_if_missing(false)` 让路径错误直接失败
- **命令**：`test_connection` / `save_connection` / `list_connections` / `delete_connection`（save/delete 返回更新后列表，前端省一次 IPC+磁盘读）

## 三、批量导入控制台（/data/batch-import）

### 功能

1. **目标连接**：下拉选择已保存的 MySQL 连接（联动连接配置页），支持刷新
2. **导入文件**：对话框多选 SQL 脚本（txt/sql），展示文件名/大小，可移除；**只传路径不传内容**
3. **删除脚本（可选）**：文件选择 + 粘贴双输入（粘贴优先），每行一条 DELETE
4. **选项**：每批行数（默认 1000）、单批最大字节（默认 1MB）、强制 TLS、临时关闭外键检查、剔除自增主键列（默认开）、导出分片上限（默认 5MB）
5. **预检**：解析文件（编码/行数/坏行/批次数）、删除影响 dry-run、历史防重导告警、TLS 提示、自增列识别
6. **执行**：一键全流程（删除→批量插入→行数核对→提交/回滚），实时进度条
7. **结果报告**：提交/回滚状态、文件明细、删除行数、每表预期/实际/✓、剔除列、失败批次源行号定位
8. **导出批量脚本**：生成合并后 .sql 文件（可 ≤N MB 分片），供离线/内网环境执行

### 实现细节（Rust：[import.rs](../src-tauri/src/import.rs)）

**解析器**
- 逐行解析 `INSERT INTO \`t\` (...) VALUES (...);`：表名提取 → 括号深度匹配列清单 → `split_top_level` 顶层逗号切分（正确处理字符串内逗号/括号、`\` 转义、`''` 双写转义、函数括号），列数与值数不一致计坏行（前 20 条样例留档）
- 编码：严格 UTF-8（去 BOM）→ 回退 GB18030（encoding_rs）；sha256 每次现算
- 重文件操作全部在 `spawn_blocking`，不阻塞异步运行时；74MB 单遍解析约 1 秒

**批量合并**：同表连续行合并为多 VALUES 语句，双上限（行数 / 字节预算 `min(用户设置, max_allowed_packet/2)`——连接后探测服务器 packet）；50,655 行 → ~53 条语句；每批记录源行号范围用于失败定位「第 N 批（源文件第 a-b 行）」

**自增列剔除**：information_schema 参数化查询识别各表自增列 → 列清单与每行值按同一序号同步剔除 → 目标库重新生成主键。两遍解析：先发现表、再带映射重解析（无命中零成本）

**执行管线（单事务）**：
```
连接(5s超时/可选TLS Required) → 解析 → 历史防重导检查
→ BEGIN → 删除脚本逐条 → 批量 INSERT（rows_affected 按表累加）
→ 行数核对（expected==actual，不符即失败）→ COMMIT / ROLLBACK
→ 写台账（含重放配置）→ 运行日志
```
- **唯一/外键约束始终开启**（除非用户开「临时关外键」选项），坏数据直接失败回滚而非静默补救
- 连接断开时 InnoDB 自动回滚整个事务，数据安全
- 进度通过 `app.emit("import-progress")` 事件推送（stage/percent/message）

**删除 dry-run**：事务内执行全部 DELETE 收集 rows_affected 后回滚——精确影响行数、零数据变更；全 0 时自动跳过删除步骤

**导出**：连接可选（选了且连通→做自增剔除；未选→原样导出+警告）；按批次边界分片，每片独立事务（头注释+SET+语句+COMMIT），文件头含源文件 sha256 与分片序号

**防重导**：sha256 台账命中 → 预检告警 + 执行层拒绝（`skip_history_warning` 放行），重复导入必须经用户明确确认

## 四、导入日志（/data/import-log）

### 功能

- **运行日志 Tab**：最近 500 行、等宽展示、自动滚底、刷新/清空
- **导入历史 Tab**：列表 + 明细行展示；条件查询（结果/关键字/时间范围）；手工登记（软件外执行的导入留痕）；编辑（说明/时间/文件明细）；删除（确认）；**一键重新执行**（回填原配置并自动预检）

### 实现细节

**运行日志（[runlog.rs](../src-tauri/src/runlog.rs)）**
- 追加型文本 `{app_config_dir}/import_log.txt`，格式 `[UTC时间] [阶段] 内容`；5MB 自动轮转备份为 `.1`（只留两代）
- 时间戳用 civil-from-days 算法生成（零 chrono 依赖）；写入在 spawn_blocking，失败静默不影响主流程
- 记录节点：预检开始/完成（含历史命中数）、导入开始/结束（提交/回滚、行数、耗时、失败原因）、导出完成

**导入历史（[history.rs](../src-tauri/src/history.rs)）**
- SQLite：`{app_config_dir}/import_history.db`（WAL 模式，`at_ms`/`sha256` 索引）；旧 `import_history.json` 首次使用自动迁移并归档 `.migrated`
- 表结构：`import_records`（每文件一行：run_id/sha256/file_name/rows/tables_json/ok/at_ms）+ `run_meta`（run_id → remark + config_json）；同批文件共享 run_id，查询按 run 聚合
- 查询：keyword（说明/文件名 LIKE）+ 结果 + 时间范围，参数化，最新在前，上限 200 批
- **重放配置**（ReplayConfig）：执行成功时把文件路径、连接 id、删除脚本、全部选项序列化进 `config_json`；旧版本记录该值为 null → 前端「重新执行」置灰并提示
- 手工登记/编辑/删除：sha256 置空（不参与防重导匹配）、事务内删除重插明细

## 六、关键安全与正确性设计

1. **提交前核对**：行数核对基于 rows_affected 累加（零 COUNT 扫描），任何不符自动回滚——导入要么完整成功要么完整失败
2. **事务原子性**：删除、插入在同一事务，连接断开/失败时 InnoDB 自动回滚，不会出现半套数据
3. **防重导**：sha256 台账 + 预检告警 + 执行层双重拦截
4. **约束不静默绕过**：唯一/外键检查默认开启；「临时关外键」为显式选择项且报告中有提示
5. **删除保护**：删除脚本执行前必过 dry-run 影响行数确认弹窗
6. **大文件不过 IPC**：导入文件只传路径，Rust 直读磁盘
7. **并发安全**：导入任务 IMPORT_LOCK 串行化；台账写入 SQLite WAL + HISTORY_LOCK；连接配置 tokio Mutex
8. **已接受取舍（代码注释声明）**：连接密码明文存本地 JSON（本地单用户工具）
